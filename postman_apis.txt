====================================================================
               ALPHABIT SKILL BACKEND API DOCUMENTATION
====================================================================
Base URL: http://localhost:5000/api

*Note on Authentication:*
All "/admin/*" endpoints require an Authorization Header:
Header Key  : Authorization
Header Value: Bearer <your_jwt_token>

1. HEALTH CHECK & SYSTEM
====================================================================

Health Check Status
- Method : GET
- URL    : /health
- Auth   : None
- Response:
{
  "status": "success",
  "message": "API is healthy"
}

2. AUTHENTICATION & USERS
====================================================================

Register New User
- Method  : POST
- URL     : /users/register
- Headers : Content-Type: application/json
- Body (JSON):
{
  "name": "Admin User",
  "email": "admin@example.com",
  "password": "password123"
}

Login User / Get JWT Token
- Method  : POST
- URL     : /users/login
- Headers : Content-Type: application/json
- Body (JSON):
{
  "email": "admin@example.com",
  "password": "password123"
}
- Response Example:
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "66a8b123...",
    "name": "Admin User",
    "email": "admin@example.com"
  }
}

3. FILE & MEDIA UPLOADS (CLOUDINARY)
====================================================================

Upload Any Single File / PDF / Image
- Method  : POST
- URL     : /upload
- Headers : Content-Type: multipart/form-data
- Body (form-data):
  - file (file): Select PDF file or Image file (.pdf, .jpg, .png, .webp)
  - OR pdf (file): Select PDF file
  - OR image (file): Select Image file
- Response Example:
{
  "message": "PDF uploaded successfully",
  "fileUrl": "https://res.cloudinary.com/dn4blj1nq/raw/upload/v178514/alphabit_skill_admin/pdf-178514.pdf",
  "imageUrl": "https://res.cloudinary.com/dn4blj1nq/raw/upload/v178514/alphabit_skill_admin/pdf-178514.pdf",
  "pdfUrl": "https://res.cloudinary.com/dn4blj1nq/raw/upload/v178514/alphabit_skill_admin/pdf-178514.pdf"
}

Upload PDF Specifically
- Method  : POST
- URL     : /upload/pdf
- Headers : Content-Type: multipart/form-data
- Body (form-data):
  - pdf (file): Select PDF document file

4. SYLLABUS & CURRICULUM PDF MODULE (SLUG-BASED)
====================================================================

Get Single Syllabus PDF By Skill Slug (Public Frontend Route)
- Method  : GET
- URL     : /syllabus/slug/:slug
- Example : /syllabus/slug/full-stack-development
- Auth    : None
- Response Example:
{
  "success": true,
  "data": {
    "_id": "66a8c1f9ef1234567890abcd",
    "skillSlug": "full-stack-development",
    "pdfUrl": "https://res.cloudinary.com/dn4blj1nq/raw/upload/v178514/alphabit_skill_admin/pdf-178514.pdf",
    "title": "full-stack-development",
    "createdAt": "2026-07-30T16:44:00.000Z"
  }
}

Get All Syllabus Items (Public)
- Method  : GET
- URL     : /syllabus
- Query Params (Optional):
  - ?slug=full-stack-development
  - ?skillSlug=web-development

Get Single Syllabus By ID
- Method  : GET
- URL     : /syllabus/:id

Create Syllabus PDF (Admin)
- Method  : POST
- URL     : /admin/syllabus
- Headers : Key: Authorization, Value: Bearer <your_jwt_token>
- Body (form-data):
  - skillSlug (text): "full-stack-development"
  - pdf (file): Select PDF file to upload directly
  - pdfUrl (text): "https://res.cloudinary.com/..." [Optional if uploading file]

Update Syllabus PDF By ID (Admin)
- Method  : PUT
- URL     : /admin/syllabus/:id
- Headers : Key: Authorization, Value: Bearer <your_jwt_token>
- Body (form-data):
  - skillSlug (text): "web-development" [Optional]
  - pdf (file): Select new PDF file [Optional]
  - pdfUrl (text): "https://res.cloudinary.com/..." [Optional]

Delete Syllabus PDF By ID (Admin)
- Method  : DELETE
- URL     : /admin/syllabus/:id
- Headers : Key: Authorization, Value: Bearer <your_jwt_token>

Delete Meeting By ID (Admin)

9. CONTACT FORM & INQUIRIES
====================================================================

Submit Contact Form Message (Public Frontend)
- Method  : POST
- URL     : /contacts
- Headers : Content-Type: application/json
- Auth    : None
- Body (JSON):
{
  "firstName": "John",
  "lastName": "Doe",
  "email": "john.doe@example.com",
  "contactNumber": "9876543210",
  "subject": "Inquiry regarding MERN Stack Course",
  "message": "Hello, I would like to get more information about the upcoming course schedule and fees."
}
- Response Example:
{
  "success": true,
  "message": "Contact form message submitted successfully.",
  "data": {
    "_id": "66a8d4e5f1234567890abcd",
    "firstName": "John",
    "lastName": "Doe",
    "email": "john.doe@example.com",
    "contactNumber": "9876543210",
    "subject": "Inquiry regarding MERN Stack Course",
    "message": "Hello, I would like to get more information...",
    "status": "unread",
    "createdAt": "2026-08-04T11:00:00.000Z"
  }
}

Get All Contact Form Messages (Admin)
- Method  : GET
- URL     : /admin/contacts
- Headers : Key: Authorization, Value: Bearer <your_jwt_token>
- Response Example:
{
  "success": true,
  "count": 1,
  "data": [
    {
      "_id": "66a8d4e5f1234567890abcd",
      "firstName": "John",
      "lastName": "Doe",
      "email": "john.doe@example.com",
      "contactNumber": "9876543210",
      "subject": "Inquiry regarding MERN Stack Course",
      "message": "Hello, I would like to get more information...",
      "status": "unread",
      "createdAt": "2026-08-04T11:00:00.000Z"
    }
  ]
}

Update Contact Message Status (Admin)
- Method  : PATCH
- URL     : /admin/contacts/:id/status
- Headers : Key: Authorization, Value: Bearer <your_jwt_token>, Content-Type: application/json
- Body (JSON):
{
  "status": "read"
}
*Note:* Allowed status values: "unread" | "read" | "responded"
- Response Example:
{
  "success": true,
  "data": {
    "_id": "66a8d4e5f1234567890abcd",
    "status": "read"
  }
}

Delete Contact Message By ID (Admin)
- Method  : DELETE
- URL     : /admin/contacts/:id
- Headers : Key: Authorization, Value: Bearer <your_jwt_token>
- Response Example:
{
  "success": true,
  "data": {}
}
